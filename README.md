# AEGIS Discord Bot

地震・津波・緊急地震速報（EEW）と天気を Discord に届ける防災 Bot です。
既存の防災アシスタント **AEGIS** のデータ取得・判定ロジック（P2P地震情報 /
Open-Meteo、震度階級や重要度の規則）を Discord Bot として再構成したものです。

## できること

- **地震情報の自動通知**: P2P地震情報（気象庁）を 30 秒間隔で監視し、
  登録チャンネルへ震度付きの埋め込みで通知します。続報で最大震度が上がった
  場合は「続報」として再通知します。発生から 15 分以上経った情報や、
  Bot 起動時点で既に出ている情報は通知しません。
- **津波情報の自動通知**: 警報・注意報・解除をすべて通知します。
- **緊急地震速報（EEW）**: 推定最大震度 4 以上（または震度不明）を通知します。
  高崎・大宮については主要動の到達予想（発表値、無ければ震源距離と
  S波 3.5km/s からの推定）も併記します。取消報は、元の速報を通知済みの
  チャンネルにだけ届きます。
- **天気コマンド**: 任意の地名、または既定の高崎・大宮の天気を、
  現在の天気＋週間予報の表形式で表示します。

## コマンド

| コマンド | 内容 |
|---|---|
| `/quake` | 最新の地震情報と、最近の地震の一覧 |
| `/weather [place]` | 天気予報。`place` 省略時は高崎と大宮 |
| `/watch` | このチャンネルを通知先に登録（サーバー管理権限が必要） |
| `/unwatch` | このチャンネルの通知登録を解除（同上） |
| `/watchlist` | このサーバーの通知登録状況 |

`/watch` のオプション:

- `min_scale`: 通知する最小震度（既定: 震度3）
- `eew`: 緊急地震速報も通知するか（既定: する）
- `strong_mention`: 震度5弱以上（津波警報級も）で `@everyone` を付けるか
  （既定: 付けない）

## セットアップ

1. [Discord 開発者ポータル](https://discord.com/developers/applications) で
   アプリケーションを作成し、Bot を追加します。**特権インテントは不要**です
   （Guilds のみで動作します）。
2. Bot をサーバーへ招待します。スコープは `bot` と `applications.commands`、
   権限は「メッセージを送信」「埋め込みリンク」があれば十分です。
3. `.env.example` を `.env` にコピーし、`DISCORD_TOKEN` と `CLIENT_ID` を
   設定します。開発中は `GUILD_ID` を設定するとコマンド登録が即時反映されます。
4. 起動します。コマンドは起動時に自動登録されます。

```bash
npm install
npm run build
npm start
```

登録だけを先に行いたい場合は `npm run deploy` が使えます。

## トークンなしで動作を確認する

実データを取得して、通知・表示される内容をそのまま標準出力に出すデモがあります。

```bash
npm run build
npm run demo
```

## 仕様メモ

- データ出典: 地震・津波・EEW は P2P地震情報 API（気象庁の情報を配信）、
  天気は Open-Meteo。いずれも無料・キー不要の API です。
- ポーリング間隔は `POLL_SECONDS`（既定 30 秒、最小 10 秒）。取得に失敗した
  場合は指数バックオフ（上限 300 秒）で再試行します。
- 状態（通知登録と通知済み記録）は `data/state.json` に保存します。
- EEW の到達予想は目安です。実際の避難判断は公式の発表に従ってください。

## 注意

この Bot は個人・コミュニティ向けの補助ツールです。災害時の情報源は
気象庁・自治体などの公式発表を必ず確認してください。
